# Tableaux

Les copies inchangées des trois rapports HTML TerrSet fournis sont dans `terrset/`. Les lignes correspondent aux classes cartographiées et les colonnes à la référence d’entraînement CLC 2018. Ce sont des matrices de confusion, pas des transitions temporelles ni une validation indépendante. Les matrices diachroniques CSV doivent être ajoutées après un calcul réel avec leur provenance.
