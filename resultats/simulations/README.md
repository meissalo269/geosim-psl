# Simulations

Destination des scénarios Markov/CA-Markov réellement calculés, limités à 2030 dans l’interface. Aucun scénario n’est créé dans cette préparation. Joindre aux GeoTIFF/PNG la calibration, la matrice P, la graine, les classes, le support valide et le journal. Une prédiction ne constitue jamais une observation historique.
